## 2. Карта — Яндекс MapKit, ключ не в репозитории

**Что.** На экране адреса карта `yandex_maps_mapkit_lite`. Метка — точка из
базы, синий знак карты — телефон. Ключ читается при сборке из
`mapkit_api_key.json` через `--dart-define-from-file`. Файл в `.gitignore`.

**Почему.** Водителю нужно видеть, куда ехать, а не только строку координат.
Облегчённый MapKit рисует карту и положение, без маршрутов и поиска.
Логотип Яндекса остаётся на карте, в «О программе» есть ссылка на условия.

**Что следует.** Запуск: `flutter run --dart-define-from-file=mapkit_api_key.json`.
Без этого файла карта на экране пустая, остальное приложение работает.
Сборка Android идёт на JDK 21: классы MapKit новее, чем JDK 17 из Android Studio.

## 1. База на телефоне, кнопка не трогает кадастр

**Что.** Адреса лежат в SQLite через пакет `sqlite3`, без Drift. Учебный
набор выдуман: у большинства улиц точка центра посёлка, у одного переулка
точка линии улицы.

Кнопка «Это тут» пишет координату только если точность GPS не хуже 50 метров
и текущая точка не является домом из кадастра. Прежние широта, долгота и
точность остаются в строке, «Вернуть приближённую точку» кладёт их обратно.

**Почему.** Водителю нужно доехать и отметить дом, которого нет в реестре.
Точную кадастровую точку этим жестом затирать нельзя: она уже лучше, чем
ручной GPS. Изолят чтения, как в LawMatic, не нужен: файл не общий с другим
приложением, правка — одна строка.

**Что следует.** Выгрузка из настроек копирует в буфер только отмеченные
водителем адреса. Подключение полного реестра и сервера — отдельный шаг.
