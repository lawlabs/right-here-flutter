# Это тут

Водитель доезжает до дома, которого нет в адресном реестре, и отмечает его там, где стоит. Это телефонное приложение для Android: список адресов, карта и одна кнопка.

Геокодер часто знает только центр посёлка или линию улицы. Номера дома на такой карте нет. Водителю всё равно нужно понять, куда ехать, найти дом глазами и сохранить координату места. Точку дома из кадастра это касание не затирает: она уже точнее ручного GPS.

## Как это работает

Три вкладки: «Ждут», «Отмечены», «Настройки».

1. В «Ждут» дома, у которых в базе центр населённого пункта, линия улицы или соседний дом.
2. На экране адреса карта показывает точку из базы. Синий знак на карте — телефон.
3. Кнопка «Это тут» включается, когда точность GPS лучше 50 метров.
4. Прежняя широта, долгота и источник точки остаются в строке. «Вернуть приближённую точку» кладёт их обратно.
5. В настройках отмеченные адреса копируются в буфер обмена как CSV.

База лежит на телефоне, в SQLite. Полный реестр и сервер подключаются отдельно. Сейчас в базе учебный посёлок Примерный: улицы, дома и счета выдуманы, чтобы можно было открыть приложение и пройти сценарий.

## Карта

Карта — Яндекс MapKit в облегчённом варианте: рисунок карты и положение, без маршрутов и поиска. Ключ в репозиторий не входит.

Положите в корень проекта файл `mapkit_api_key.json`:

```json
{
  "MAPKIT_API_KEY": "ключ из кабинета разработчика Яндекса"
}
```

Запуск:

```bash
flutter run --dart-define-from-file=mapkit_api_key.json
```

Без этого файла карта на экране пустая, списки и отметка работают. Условия использования Яндекс Карт: https://yandex.ru/legal/maps_api/ru/

## Сборка

Нужны Flutter с Dart 3.12 и телефон или эмулятор на Android 8.0 и новее.

MapKit 4.45 собран под Java 21. Если сборка не читает его классы, укажите JDK 21 в своём `~/.gradle/gradle.properties`:

```properties
org.gradle.java.home=/path/to/jdk-21
```

Правила кнопки проверяются так:

```bash
flutter test
```

## Из чего собрано

Flutter, Riverpod, SQLite через пакет `sqlite3`, геолокация телефона и Яндекс MapKit Lite.
